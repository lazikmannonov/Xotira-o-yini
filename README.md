# Xotira o'yini

HTML, CSS va JavaScript bilan yozilgan oddiy xotira o'yini. 16 ta karta ichidan bir xil rasmli juftliklarni toping.

## Imkoniyatlar

- yurishlar va vaqt hisobi
- eng yaxshi natija (rekord) brauzerda saqlanadi
- telefon va kompyuterda ishlaydi
- yorug va qorong'i rejim

## Ishga tushirish

`index.html` faylini brauzerda oching.
